# Restaurante Bassalo — Yecla

Web oficial del **Restaurante Bassalo**, mesón asador en Yecla (Murcia).

Es una página estática de un solo archivo (`index.html`): no necesita servidor,
ni base de datos, ni instalar nada. Está en **español e inglés** a la vez, con un
botón para cambiar de idioma, y funciona igual de bien en móvil y en ordenador.

---

## 🌐 Cómo publicarla gratis en internet (GitHub Pages)

1. Sube esta carpeta a un repositorio de GitHub (ver más abajo si aún no lo has hecho).
2. En el repositorio, entra en **Settings → Pages**.
3. En **Source**, elige la rama `main` (o `master`) y la carpeta `/ (root)`. Guarda.
4. En un par de minutos tu web estará publicada en una dirección tipo:
   `https://tu-usuario.github.io/tu-repositorio/`

No hay que configurar nada más: la web ya incluye un archivo `.nojekyll` para que
GitHub la sirva tal cual.

> ¿Prefieres otro hosting? Estos mismos archivos funcionan en Hostinger, Netlify,
> Cloudflare Pages o cualquier sitio que acepte archivos estáticos. El archivo de
> inicio es siempre `index.html`.

## 📁 Qué hay en la carpeta

| Archivo / carpeta        | Para qué sirve                                              |
|--------------------------|------------------------------------------------------------|
| `index.html`             | **La web.** Es el archivo principal.                       |
| `images/`                | Fotos de los platos, el logo y los fondos (en `.webp`).    |
| `videos/hero-bassalo.mp4`| Vídeo de la portada (comprimido, ~1,3 MB).                 |
| `.nojekyll`              | Necesario para GitHub Pages. No lo borres.                 |
| `LEEME - Instrucciones.txt` | Guía sencilla para editar textos, teléfono y fotos.     |
| `Bassalo.dc.html`, `support.js` | Archivos de diseño de origen. **No hacen falta** para que la web funcione; se guardan solo como copia. |

---

## ✏️ Editar la web

Para cambiar textos, el teléfono o las fotos, abre **`LEEME - Instrucciones.txt`**:
está explicado paso a paso y sin tecnicismos.
